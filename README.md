# Cafeteria Tradicional — Site Institucional

Site estático criado para a 1ª Avaliação do IC. Projeto que apresenta uma cafeteria fictícia com foco em HTML semântico, CSS organizado e acessibilidade básica.

## Decisões importantes de design/código
1. Uso de tags semânticas (`header`, `nav`, `main`, `footer`) para melhor acessibilidade.
2. Layout com Flexbox e regras responsivas simples para atender o desafio bônus.
3. Paleta reduzida com variáveis CSS para facilitar manutenção e contraste suficiente para leitura.
